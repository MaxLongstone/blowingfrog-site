# ElevenLabs -- what is still missing

Everything below is a sound effect or a piece of music the game already expects and does not
have yet. Each box is a complete prompt: paste it as it is into ElevenLabs Sound Effects (for the
SFX) or Music (for the music and stings), set the length shown, and save the result under the
name in bold above the box (as .mp3, into the usual folder). Nothing here needs any other setup.

This list is generated from the game's own config, so it is never stale: if something below turns
out to already be sitting in `assets/sfx` or `assets/music` next time this is run, it drops off.
